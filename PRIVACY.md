# Privacy Policy — Nisteia

The policy now lives at **<https://stforge.dev/nisteia/privacy>**, which is the
URL declared in Play Console.

It used to be served from this file over GitHub. Keeping the full text in two
places only guarantees that one of them goes stale, so this file is a pointer
and the site is the single source of truth. Source:
[`stforge-site`](https://github.com/SamedTemiz/stforge-site) →
`nisteia/privacy/index.html`.

The substance has not changed: Nisteia collects no data, has no account, no
analytics, no ads, and makes no network requests.
